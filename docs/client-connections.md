# Project-local client connections

AssertLedger can prepare a read-only MCP connection and install its packaged skill inside one
repository. Run these commands from the installed package after `dist/cli.js` has been built.

## Preview first

`connect` and `disconnect` are previews unless `--write` is present. A connection preview lists
every managed path and prints the complete planned contents between explicit delimiters. A removal
preview lists the paths that would be checked. Neither preview changes the repository.

```console
assertledger connect . --client codex
assertledger connect . --client claude-code
assertledger disconnect . --client codex
```

Use `--write` only after reviewing the paths:

```console
assertledger connect . --client codex --write
assertledger disconnect . --client codex --write
```

The operation is idempotent. Reinstalling identical artifacts reports `UNCHANGED`; removing an
already absent installation reports `ABSENT`.

## Managed artifacts

| Client | MCP configuration | Packaged skill |
| --- | --- | --- |
| Codex | `.codex/config.toml` | `.agents/skills/assertledger/SKILL.md` |
| Claude Code | `.mcp.json` | `.claude/skills/assertledger/SKILL.md` |

The skill is copied byte-for-byte from the versioned `integrations/skill/SKILL.md` included in the
installed AssertLedger package, including its frontmatter.

Both configurations start `assertledger mcp --root <canonical-repository-root>`. The default server
is read-only. Installing a connection does not authorize candidate execution, trust the repository,
or reload the client; those remain explicit operator actions.

AssertLedger creates a managed file only when it is absent. If any target already contains different
content, the complete operation reports `CONFLICT` before writing anything. Linked paths,
directories in place of files, and other non-regular targets are refused.

`disconnect --write` removes only files that still match the exact bytes shipped or generated by the
current AssertLedger installation. If a person or another tool changed either file, the complete
removal reports `CONFLICT` and leaves every artifact in place. Directories are never removed.

## Generic MCP descriptor

Other MCP clients can request a transport descriptor:

```console
assertledger connect . --client mcp
```

The command prints a JSON object with `transport`, `command`, `args`, and `cwd`. AssertLedger does not
write this descriptor because MCP clients do not share a universal project configuration path or
file format. Copy the fields into the client-specific configuration after checking that client's
documentation.
